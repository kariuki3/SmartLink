# SmartLink – Internet & Networking Solutions

## Project Overview

SmartLink is a web-based platform designed to connect customers with reliable internet installation services and networking solutions.

The website allows visitors to explore available internet packages, browse networking devices, and contact the SmartLink team for installation services and customer support.

## Project Objectives

- Showcase available internet packages.
- Allow customers to explore networking devices.
- Provide information about internet installation services.
- Make it easy for customers to contact the support team.
- Create an accessible and user-friendly online experience.

## Website Features

- **Home Page:** Introduces SmartLink and its services.
- **Packages Page:** Displays available internet packages.
- **Products Page:** Showcases networking devices available for purchase.
- **Contact & Support Page:** Allows customers to reach SmartLink for inquiries and assistance.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Website styling and layout.
- JavaScript – Website interactivity.
- Git – Version control.
- GitHub – Source code hosting and project management.

## Getting Started

To view the website locally:

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `Index.html` in your browser.

Alternatively, use the VS Code Live Server extension to launch the website.
