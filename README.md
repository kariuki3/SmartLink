# SmartLink Website

A responsive website for SmartLink, showcasing internet packages, networking equipment, company information and customer support.

## Website Pages

- `Index.html` — Home page and service overview.
- `about.html` — About SmartLink, mission, vision and values.
- `packages.html` — Home and business internet packages with direct WhatsApp enquiries.
- `products.html` — Networking product catalogue with photographs, descriptions, indicative prices and direct WhatsApp enquiries.
- `contact.html` — Contact information, enquiry form and frequently asked questions.

## JavaScript

All page interactions and product/package data are combined in one shared file: `style/script.js`. Functions and event handlers include explanatory comments.

## Technologies

- HTML5
- CSS3
- JavaScript
- WebP images
- WhatsApp click-to-chat links

## Website Features

- Responsive desktop, tablet and mobile layouts
- Shared stylesheet and sticky navigation
- Vertical social media links
- Home and business internet package sections
- Product catalogue with multiple photographs per product
- Alternate product image on hover
- Product detail gallery
- Indicative product prices in Kenyan shillings
- Direct WhatsApp enquiries for products and packages
- Contact form validation with WhatsApp submission
- FAQ accordion

## Running the Website

1. Open the `SmartLink` folder in Visual Studio Code.
2. Start Live Server using `Index.html`.
3. Browse the website pages.
4. Select a product or package and use the WhatsApp button to contact SmartLink.
